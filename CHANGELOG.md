# Changelog

## 1.0.0 — Research foundation (2026-11-20)

### Added

- Rebranded the repository from `remnants` to **ClioFactors**, with a documented scope.
- Installable `cliofactors` Python package, offline CLI and seven explicit historical data catalogs.
- Reproducible Massachusetts manufacturing Cobb–Douglas regression, levels and growth specifications.
- HAC descriptive standard errors, model diagnostics, aligned CSV observations, JSON, Markdown and PNG artifacts.
- SHA-256 verification of all unchanged bundled ZIP datasets.
- End-to-end examples, architecture/methodology/source documentation, data and license cautions.
- Automated test suite and GitHub Actions CI.
- Original 38 Python scripts and miscellaneous supplied data preserved in `legacy/`.

### Deliberately out of scope

- Incomplete external BEA/FRB historical sources and archived untested scripts.
- Modern data refreshes, causal-identification claims, policy advice and broad econometric validation.
- Public redistribution approval for historical third-party datasets.
